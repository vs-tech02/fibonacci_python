# Fibonacci Series in Python

## 📌 About the Project

This repository contains a beginner-friendly Python program that prints the Fibonacci series for a specified number of terms.

The program takes the number of terms as input, initializes the first two Fibonacci numbers as `0` and `1`, and uses a `for` loop to print the series.

## 🚀 How to Run

1. Make sure Python is installed on your computer.
2. Download or clone the repository.
3. Open a terminal in the folder containing `fibonacci.py`.
4. Run the following command:

   ```bash
   python fibonacci.py
   ```

   If your system uses `python3`, run:

   ```bash
   python3 fibonacci.py
   ```

5. Enter the number of terms when prompted.

## 🎯 Learning Objective

The objective of this program is to understand:

- How to take integer input from the user using `input()` and `int()`.
- How to use a `for` loop with `range()`.
- How to initialize and update multiple variables.
- How to generate a sequence using addition.
- How to print values on the same line using `print()` with `end=" "`.

## 🧠 What Is the Fibonacci Series?

The Fibonacci series is a sequence in which each number is the sum of the two preceding numbers, starting with `0` and `1`.

For example, the first seven terms are:

```text
0 1 1 2 3 5 8
```
